# md-glance 使用指南

md-glance 是一款简洁高效的 macOS Markdown 预览工具，专注于提供流畅的文档阅读体验。

## 功能特性

### 文档预览

- 支持 GitHub Flavored Markdown (GFM) 语法
- 支持数学公式 (LaTeX/KaTeX)
- 支持流程图和图表 (Mermaid)
- 代码高亮显示

### 文件操作

- **打开文件**：`⌘O` 或拖放 .md 文件到窗口
- **多标签页**：拖放新文件到已打开的窗口会创建新标签页
- **实时刷新**：文件保存后自动更新预览

### 导航功能

- **目录侧边栏**：点击工具栏目录图标显示/隐藏
- **滚动进度条**：顶部显示当前阅读进度
- **标题跳转**：点击目录项快速跳转到对应章节

### 文档统计

- 工具栏显示当前文档的字数和行数
- 支持中英文混合统计

### 快捷操作

- **复制全文**：点击工具栏复制按钮，一键复制整个文档
- **隐藏滚动条**：提供沉浸式阅读体验

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘O` | 打开文件 |
| `⌘W` | 关闭当前标签/窗口 |

## 支持的 Markdown 语法

### 标题

    # 一级标题
    ## 二级标题
    ### 三级标题

### 强调

    **粗体** *斜体* ~~删除线~~

### 列表

    - 无序列表
    1. 有序列表
    - [ ] 任务列表

### 代码

行内代码：`code`

代码块（使用三个反引号围栏，无需缩进）：

```swift
print("Hello, World!")
```

### 表格

| 列1 | 列2 |
|-----|-----|
| 内容 | 内容 |

### 数学公式

行内公式：$E = mc^2$

块级公式：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

### Mermaid 图表

语法示例（4空格缩进）：

    ```mermaid
    graph LR
        A[开始] --> B[结束]
    ```

渲染效果：

```mermaid
graph LR
    A[md-glance] --> B[打开文件]
    B --> C[渲染预览]
    C --> D[实时刷新]
```

## 系统要求

- macOS 12.0 (Monterey) 及以上
- 支持 Intel 和 Apple Silicon
