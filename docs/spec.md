# md-glance — macOS Markdown 预览工具需求规格

**文档版本**：v1.1  
**编写日期**：2026-02-27  
**项目状态**：需求确认

---

## 1. 项目概述

### 1.1 项目背景

为满足在 macOS 环境下快速查看 Markdown (`.md`) 文件渲染效果的需求，开发一款轻量级的原生桌面预览工具。

### 1.2 项目目标

打造一款极简、高效、无干扰的 Markdown 阅读器，专注于"预览"这一单一功能，不提供编辑能力。

### 1.3 项目范围

- **包含**：文件读取、内容渲染（含 GFM / LaTeX / Mermaid）、实时刷新。
- **不包含**：文本编辑、文件导出、云同步、多标签页、自定义主题等复杂功能。

## 2. 功能需求

| ID | 功能模块 | 需求描述 | 优先级 |
| :--- | :--- | :--- | :--- |
| FR-01 | 文件打开 | 用户可通过以下方式打开文件：1) 菜单栏 `File → Open`；2) 快捷键 `Cmd + O`；3) 将 `.md` 文件拖拽至应用窗口或 Dock 图标。 | P0 |
| FR-02 | 内容渲染 | 将 Markdown 文本渲染为美观的 HTML 格式，需支持标准 Markdown 语法及 GFM (GitHub Flavored Markdown)，包括表格、任务列表、脚注、代码块语法高亮等。 | P0 |
| FR-03 | LaTeX / Mermaid | 支持渲染 LaTeX 数学公式（行内 `$...$` 及块级 `$$...$$`）和 Mermaid 图表。 | P0 |
| FR-04 | 实时监控 | 后台监控当前打开的文件，当文件在外部被修改（如使用 VS Code 保存）时，预览窗口自动刷新显示最新内容。 | P0 |
| FR-05 | 滚动保持 | 文件自动刷新时，保持当前滚动位置不变。 | P0 |
| FR-06 | 资源解析 | 正确解析 Markdown 中的相对路径资源（图片等），以文件所在目录为基准路径。 | P0 |
| FR-07 | 窗口标题 | 窗口标题显示当前正在预览的文件名。 | P1 |
| FR-08 | 链接处理 | 点击渲染内容中的外部链接，使用系统默认浏览器打开。 | P1 |
| FR-09 | QuickLook 扩展 | 提供 macOS QuickLook 插件，支持在 Finder 中按空格预览 `.md` 文件渲染结果。 | P1 |
| FR-10 | CLI 支持 | 提供命令行工具，支持 `md-glance <file.md>` 直接打开预览窗口。 | P2 |

## 3. 非功能需求

| ID | 类别 | 需求描述 |
| :--- | :--- | :--- |
| NFR-01 | 性能 | 应用启动时间 < 2 秒；文件打开及渲染时间 < 500ms。 |
| NFR-02 | 兼容性 | 支持 macOS 12.0 (Monterey) 及以上版本；同时支持 Intel (x86_64) 和 Apple Silicon (arm64) 架构。 |
| NFR-03 | 资源占用 | 应用 idle 状态下内存占用 < 50MB。 |

---

## 4. UI/UX 需求

### 4.1 界面布局

单窗口布局，主体为一个可滚动的内容渲染区域。

### 4.2 视觉风格

- 遵循 macOS Human Interface Guidelines (HIG)。
- 渲染样式默认采用 **GitHub 风格** CSS，确保代码块、表格等元素美观易读。
- 支持系统**深色模式** (Dark Mode) 自动切换。

### 4.3 交互状态

| 状态 | 描述 |
| :--- | :--- |
| 初始状态 | 显示占位符提示 "Open a Markdown file to get started"。 |
| 阅读状态 | 全屏显示渲染后的文档内容。 |

## 5. 技术选型

| 维度 | 方案 | 说明 |
| :--- | :--- | :--- |
| 开发语言 | Swift | — |
| UI 框架 | SwiftUI | — |
| Markdown 渲染 | cmark-gfm + WKWebView | 完整 GFM 支持，CSS 自由定制，便于集成 LaTeX / Mermaid。 |
| 数学公式 | KaTeX (JS) | 通过 WKWebView 加载，渲染 LaTeX 公式。 |
| 图表 | Mermaid (JS) | 通过 WKWebView 加载，渲染 Mermaid 图表。 |
| 代码高亮 | highlight.js / Prism (JS) | 通过 WKWebView 加载，渲染代码块语法高亮。 |
| 渲染样式 | GitHub Markdown CSS | 默认主题，支持 Light / Dark 自动切换。 |
| 文件监控 | DispatchSource + FSEvents 兜底 | 处理"删除后重建"等编辑器保存行为的边界情况。 |

---

## 6. 明确不做的事项

以下功能**不在项目范围内**，以确保极简定位：

- 多标签页 / 多窗口管理
- 导出 PDF / HTML
- TOC 侧边栏 / 大纲导航
- 自定义主题 / CSS
- 文本编辑
- 云同步

---

## 7. 验收标准

1. 用户能够通过菜单、快捷键、拖拽三种方式打开任意 `.md` 文件并看到格式化内容。
2. GFM 表格、任务列表、代码块（含语法高亮）、LaTeX 公式、Mermaid 图表均正确渲染。
3. 使用外部编辑器修改并保存文件后，预览界面在 1 秒内自动更新，且滚动位置不变。
4. Markdown 中的相对路径图片正确显示。
5. 点击外部链接在系统浏览器中打开。
6. 深色模式下界面与渲染内容均正确适配。
7. 应用可通过 `.dmg` 包正常安装运行。
